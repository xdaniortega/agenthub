# 🤖 AgentHub

> Create, import, and orchestrate ERC-8004 AI agents with on-chain identity, reputation, and A2A communication.

```bash
npx agenthub
```

## Overview

AgentHub is a CLI toolkit for working with [ERC-8004](https://eips.ethereum.org/EIPS/eip-8004) AI agents on EVM chains. It lets you:

- **Create** new agents with on-chain identity, A2A/MCP servers, and pre-configured archetypes
- **Import** ERC-8004 compliance into existing projects
- **Communicate** with your deployed agents via A2A protocol
